# Saved app artifacts

Generated by `../export_models.py` from the existing lasso and logistic notebook selection. Models are fitted only on pre-cutoff training movies. Test outputs are verified against the saved notebook reports before export.

- `rating_pipeline.joblib`: preprocessing, quadratic features, and lasso regression.
- `success_pipeline.joblib`: preprocessing and three-class logistic regression (0 Bust / 1 Moderate success / 2 Hit).
- `manifest.json`: input schemas, selected parameters, hit threshold, outcome schema, class labels, versions, and dataset/code/shared-helper provenance hashes.
- `comparisons.json`: compact verified metrics for all 12 models; no duplicate prediction arrays.

These are trusted project artifacts for app loading, not user-uploaded files. Rebuild them whenever their source notebooks or model datasets change; never retrain during app startup. See the parent README for instructions.
