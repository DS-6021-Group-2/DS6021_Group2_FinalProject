# Saved app artifacts

Generated by `../export_models.py` from the existing ridge and logistic notebook selection. Models are fitted only on pre-cutoff training movies. Test outputs are verified against the saved notebook reports before export.

- `rating_pipeline.joblib`: preprocessing, quadratic features, and ridge regression.
- `success_pipeline.joblib`: preprocessing and logistic regression.
- `manifest.json`: input schemas, selected parameters, success threshold, versions, and provenance hashes.
- `comparisons.json`: compact verified metrics for all 12 models; no duplicate prediction arrays.

These are trusted project artifacts for app loading, not user-uploaded files. Rebuild them whenever their source notebooks or model datasets change; never retrain during app startup. See the parent README for instructions.
